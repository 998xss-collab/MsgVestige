# 知微 MsgVestige

**微信数据基座 —— 把你自己电脑上的微信数据变成一个可以查询的数据库。**

微信把聊天记录、联系人、群、朋友圈、转账红包都加密存在本机。这个工具把它们解密、整理成一个标准
SQLite 库，然后你可以用命令行查、用 SQL 查、或者让 AI 助手直接问。

- **只读。** 不改微信的任何东西。这不是靠自觉，是三层各自独立地写不进去：微信的库用只读文件句柄打开，
  上面那层只读存储层对任何写请求直接返回 `SQLITE_READONLY`，已解密的明文库另走 SQLite 的只读标志。
- **不上传数据。** 全程在你自己机器上跑。只有取表情包和朋友圈图片时会去微信 CDN **下载**（这两样
  本地根本不存），除此之外全程不碰网络。
- **解压即用。** 静态链接，不依赖任何非系统 DLL，不用装运行库、不用装 Python。

> ⚠️ 只能读**你自己账号**的数据 —— 密钥是从你本机正在运行的微信进程里取的。
> 拿不到别人的数据，也不该去拿。

## 下载

去 [Releases](../../releases) 拿最新的包，解压就能用：

| 包 | 大小 | 区别 |
|---|---|---|
| `msgvestige-wechat-*-windows-x64-slim.zip` | ~9 MB | 主程序，日常够用 |
| `msgvestige-wechat-*-windows-x64-full.zip` | ~117 MB | 多带 ffmpeg 和 node —— 导语音成 mp3、导朋友圈图片视频要它俩 |

**Windows 会拦一下。** 这个程序没有代码签名（证书一年好几千，alpha 阶段不值当），下载后首次运行会
弹 SmartScreen 提示。点「更多信息」→「仍要运行」即可。介意的话可以自己从源码编译。

解压后先看包里的 **`快速开始.md`** —— 每条命令和每段输出都是真机跑出来的，照着敲就能通。

## 三步跑通

```
.\msgvestige.exe auth --scan
.\msgvestige.exe ingest --no-messages --all --l1-db wx.db --wxid <你的wxid>
.\msgvestige.exe contacts --l1-db wx.db --mode cold -n 10
```

第一步从运行中的微信进程里取密钥（**不杀微信、不用重新扫码**，所以跑之前微信要开着并已登录）；
第二步建库（只导小表约 3~4 分钟、出来 1 GB 左右，聊天记录另导）；第三步就能查了。

## 能拿到什么

18 类数据落库：聊天记录、联系人、群和群成员、会话列表、朋友圈（含点赞评论）、收藏、转账、红包、
群收款、好友申请、视频号足迹、公众号推送、自定义表情、头像、陌生人等。

媒体也能导：图片、视频、语音（SILK 解码成 wav / mp3）、表情包、朋友圈图片视频。

逐类的「能不能拿到 / 从哪条路拿 / 拿不到卡在哪」看包里的 `数据可见性矩阵.md`，每一格都是真库跑出来的。

## 三种用法

- **命令行** —— 约 60 个子命令，加 `--format json` 出结构化结果。
- **HTTP 服务** —— `msgvestige serve` 起本地服务（默认只监听 127.0.0.1，别人连不上），带 OpenAPI 规格。
- **给 AI 用** —— `msgvestige mcp` 走 MCP 协议，让 Claude 这类助手直接问你的微信数据。

## 从源码编译

```
cargo build --release
```

需要较新的 Rust 工具链。Windows 上建议静态链接 CRT，不然产物会依赖 VC++ 运行库：

```
$env:RUSTFLAGS = "-C target-feature=+crt-static"
cargo build --release
```
